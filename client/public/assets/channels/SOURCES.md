# Channel marks

Bundled locally; dashboard never requests these CDNs at runtime.

- Google: existing project asset `model-brands/google-color.svg`.
- Meta, X, Naver, Apple (ASA), Reddit: SVG observed from `https://cdn.simpleicons.org/{slug}`, 2026-11-22.
- Microsoft Bing: Simple Icons 11.15.0, `https://cdn.jsdelivr.net/npm/simple-icons@11.15.0/icons/microsoftbing.svg`.
- Yahoo!: Simple Icons 7.21.0, `https://cdn.jsdelivr.net/npm/simple-icons@7.21.0/icons/yahoo.svg`.
- Yandex: Simple Icons 3.13.0, `https://cdn.jsdelivr.net/npm/simple-icons@3.13.0/icons/yandex.svg`.
- Unknown: project-authored four-square fallback. Brand marks remain their owners' trademarks; Simple Icons SVG collection is CC0.
