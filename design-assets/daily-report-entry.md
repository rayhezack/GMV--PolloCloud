# 第三栏日诊断文件夹（2026-11-10 本地实现）

## 视频对应的结构

固定白色文件夹封面，显示「日诊断 / N 份报告」。悬停或键盘进入时，真实报告纸片依次向上抽出，左右错开并轻微旋转。封面不再展示报告摘要，也不以静态标题页签替代纸片。

- 两层纸片各为一份真实报告；间隔 80ms 展开，520ms 位移过渡。
- 鼠标移出收回；点击封面可固定展开，便于触屏选择。
- 点击具体纸片打开对应正文；阅读面板可在当日已完成报告间切换。
- Escape 关闭正文并返回文件夹入口；减少动态偏好下禁用位移动效。
- 删除第三栏「查看」类链接旁的装饰箭头及更新通知标题图标，保留指标涨跌方向。

## 报告收录规则

先取异动监测中当天真实触发的端，再筛选状态为 success、报告结束日与当前日期一致的报告。监测中的日环比、周同比重复信号只生成一个端入口。

11/08 的真实监测只触发 all 和 web，因此文件夹为大盘、Web 两份报告。即使存在 App 已保存报告，也不能混入当天文件夹。没有触发、生成中、失败及其他日期的报告不计入已完成份数。

## 数据与性能

对实际异动端并行读取 `/api/daily-diagnosis?platform=…&period=…`，合并相同在途请求。只有未完成或读取失败的状态继续串行轮询，隐藏页面停止轮询，已完成报告停止轮询。正文渲染器按打开行为加载；访问入口不会调用模型。仅管理员可手动重试或重新生成。

## 当前验收范围

本地地址 http://127.0.0.1:5195/ 。日报读取另一开发目录保存的真实 2026-11-08 接口响应，验收服务拦截 POST，不能发起模型调用。左侧核心看板仍使用截至 11/04 的本地数据库副本；这两个日期差异仅存在于该只读验收环境。

本工作目录已完成前端接入及范围校验；日报后端仍在独立开发目录，未合入此目录、未随本次 UI 修改部署。不能将本地快照验收描述为线上端到端发布。
