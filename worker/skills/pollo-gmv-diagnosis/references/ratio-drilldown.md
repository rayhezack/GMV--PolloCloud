# 比率指标下钻：结构、效率与辛普森反转

本参考讲详细比率论证，不是整篇报告的核心结论模板。顶部核心结论和原因摘要遵循主 Skill 的精简业务判断规则；不在这些摘要中重复前后值。不要求报告制作卡片、着色或固定 UI 组件。

## 使用条件与边界

仅在证据包含同一筛选、同一日期覆盖、互斥且完备分组的分子与分母时使用。支付率的权重是提交人数占比，曝光率的权重是活跃人数占比；不能拿 DAU 占比解释支付率。先核对各组分子、分母之和与总体一致，再使用服务已计算的分解结果。语言模型不得从展示后四舍五入的表格反算或编造效应。

分解回答“变化集中在哪里、是人群占比还是组内效率变化”，不证明产品动作或渠道质量是根本原因。人数下降不自动代表结构恶化。

## 指标名称必须准确

局部比率判断、分组论证及必要的辛普森提示都必须使用本次诊断的完整指标名，不能一律称为“转化率”。例如付费墙曝光率诊断写“付费墙曝光率较高的 T3”“T1 自身付费墙曝光率 +xx%（A -> B），变化 +xxpp”，不能写“转化较高”“自身转化能力”。提交支付率、付费墙提交率、请求率及各留存率同理，保留其具体行为与观察窗口。

结构结论要写明目标比率较高还是较低、哪种分母人群的占比变化、从多少到多少及其 pp 影响。例如曝光率使用“活跃人数占比”，提交支付率使用“提交人数占比”。效率变化表示同一分层自身目标比率的变化，不自动意味着支付转化、渠道质量或因果效果。

## 指标变动的定量写法

详细论证中的真实指标变化使用 `+xx%（A -> B）`。比率与分母占比同时给相对变化%，需要时另给pp；Shapley结构/效率效应本身仍用pp，贡献仍用%，不能把效应当作指标前后值。基准为零或缺失时明确相对变化不可计算，不补造值。

## 守恒的对称分解

总体比率 R_t = Σ(w_it × r_it)，w_it 是组 i 占全部分母的比重，r_it 是该组分子 / 分母。

- 结构效应 S_i = (w_i1 − w_i0) × [(r_i1 + r_i0) / 2 − (R_1 + R_0) / 2]。以大盘两期平均率为参照，目标比率较低的分层占比上升为拖累，目标比率较高的分层占比上升为拉动。因为 ΣΔw = 0，中心化不改变结构总效应或守恒关系。
- 效率效应 E_i = (r_i1 − r_i0) × (w_i1 + w_i0) / 2。
- ΣS_i + ΣE_i = R_1 − R_0。内部以未舍入数据检验，展示乘 100 为百分点（pp）。

分组某一期分母为零时，该期比率没有定义。不得将缺失比率写成 0% 并称效率崩塌；应单列新增／退出人群影响，或明确计算服务采用的约定与边界。总体分母为零时不生成比率分解。净变化为零或极接近零时，只展示绝对 pp，贡献度显示“—”。

## 贡献与正负

统一贡献度 = 分项效应 / 总体带符号的净变化，禁止对分母取绝对值。总体上升时，正贡献推动上升、负贡献对冲上升；总体下降时，正贡献推动下降、负贡献对冲下降。完整分解合计 +100%，不能把正贡献直接解读为业务利好。维度加法分解、LMDI 与比率 Shapley 均使用这一语义。

绝对影响保留指标上升或下降的业务方向；贡献度正值说明同向、负值说明对冲，净变化为零时贡献度未定义。单项可超过 100%，不得强制裁剪或将对冲项归零。

## 详细比率论证

1. 一句局部判断：总体指标变化多少 pp，主因是组内效率还是人群占比，集中在哪个细分，另一侧拉动还是拖累。
2. 两条证据：提交支付率先论证结构（提交人数占比变化），再论证组内效率；各写绝对 pp、占净变化的份额及核心细分。结构和效率的主次在核心结论中明确。用“每 100 次提交，完成支付少了 X 次”辅助解释，不替换正式指标。
3. 提交支付率属于本组核心或次要因子时，保留结构/效率总效应与贡献数据表；分组证据只呈现贡献最大的组和解释净变化必需的对冲，给出相关提交占比、组内率及pp影响。两期原子人数仅在判断规模、不可比或具体论点需要时补充，不强制穷尽国家、渠道全部分类。不可比组不得填0%冒充可比，非零未归因保留必要简注。定义与边界不反复解释。建议后续核查具体渠道／支付环节，不能把分解直接写成已证实的业务根因。

示例（教学数字，禁止作为本次运行事实）：

**提交支付率 -15.00%（20.00% -> 17.00%），变化 -3.00pp，主要是各渠道内完成支付的比例下降；人群占比变化反而缓解了下滑。**

1. **效率是主要拖累：** 组内效率合计拉低 4.50pp，相当于净降幅的 150.00%；其中渠道 A 拉低 3.00pp，是优先核查对象。
2. **结构在对冲：** 人群占比变化拉高 1.50pp，抵消了部分损失，但不足以覆盖效率下降。

## 辛普森悖论判定

只有可比分组的组内变化方向与总体变化方向相反，且加权结构变化解释了总体反转时，才称“辛普森反转”。所有组支付率上升而总体下降是典型情形。只发现某一组利好、结构与效率对冲，或分解存在正负项，并不足以确认辛普森悖论；写“结构与效率方向相反”即可。小样本、缺失组和覆盖不一致须先排除，不能据此宣称反转。

用户提供的首销率示例可借鉴其“结论 → 效率证据 → 结构对冲”的写法，但“根本原因”“效率崩塌”等措辞仅在额外业务证据充分时使用，不能照搬到一般观测数据。

## 支付渠道与曝光原因的口径

- 看板统一展示“支付渠道”。计算提交支付率时，按提交时选择的渠道划分用户，以该组支付 UV / 提交 UV 计算。只包含成功支付用户的渠道记录不能充当完整提交分母。
- 渠道的某一期提交 UV 为零，或支付 UV 大于提交 UV 时，该渠道组内率没有可比定义；不能因此阻断其他可比渠道的结构与效率分析，也不能将其支付率填成 0%、删除支付 UV 或随意并入已知渠道。
- 可比渠道使用上述同一套对称 Shapley 公式，权重分母和参照率均保留完整父层口径。不可比渠道单列“未归因影响” U_i = Δ(该渠道支付 UV / 全渠道提交 UV) − 两期大盘平均提交支付率 × Δ(该渠道提交占比)。其效率、结构及对应贡献显示“—”。效率总影响 + 结构总影响 + 未归因总影响 = 整体提交支付率净变化；三者贡献合计 +100%。这是缺少组内率时的核算对账项，不是对该渠道效率或结构的推断。
- 详细论证解释组内效率、结构及主要分组；未归因项有值时说明其影响，不要求卡片或固定展示顺序。分组原子数不守恒、总分母为零、负数或非有限数仍须阻断分解。
- 曝光原因、曝光类型不适用于未曝光 DAU。按这些维度只拆曝光 UV 净变化：分类增减 / 总曝光 UV 净变化，不进行比率结构效率分解。国家维度同时具备完整 DAU 和曝光 UV 时，才可拆曝光率。
- 详细论证应写清两侧总 pp、贡献度，以及核心分层自身率或分母占比从多少变到多少。不能只写“主要变化来自某组”。


## 真实案例与动作边界

参考 `ratio-writing-examples.md` 的最近两个完整业务周案例，避免只使用教学数字。它们是有明确日期、人群与取证范围的历史参考，不是本次运行事实。净变化较小时，即使贡献度很大，也先说明 pp 和样本范围，不据此认定问题严重。

结构论证之后，组内效率的产品解释须查提供的产品动作明细。动作匹配时间、路径、范围、方向时只作为解释线索；未找到或未提供动作时写待检查，不补造根因，不直接给实验、改价、预算或渠道调整建议。完整窗口与分支见 `diagnostic-routing.md`。
