## 范例 R1：提交支付率下滑，效率拖累、结构对冲并有未归因项

范围：App × T2 × 注册老用户；按提交渠道做 Shapley 分解。这是细分人群案例，不是 App 大盘下滑；App 大盘同期上升。

**App 的 T2 老用户提交支付率 -0.37%（41.36% -> 41.21%），-0.15pp，可比渠道内效率下降是主要拖累；渠道结构和未归因项部分对冲了下滑，具体产品原因待检查。**

1. **渠道结构在缓解下滑：** 结构效应为 +0.61pp，对净变化贡献 -399.61%。apple 的提交人数占比 +9.84%（33.99% -> 37.34%），+3.35pp；其两期平均提交支付率高于该人群平均水平，带来 +0.36pp 的结构拉动。
2. **渠道内效率下降以 apple 为主要拖累：** 效率效应合计 -1.03pp，解释净降幅的 +673.77%。apple 自身提交支付率 -9.55%（54.69% -> 49.47%），-5.22pp，效率效应为 -1.86pp；google 的效率改善带来 +0.73pp，对冲部分损失。

未归因项为 +0.27pp，对净变化贡献 -174.16%；未知渠道两期提交人数均为零而支付人数 +100.00%（3 -> 6），无法计算可比组内率，不能填成 0% 或并入渠道效率。效率、结构、未归因三项合计等于 -0.15pp。

该细分净变化较小，贡献百分比超过 100% 体现较大的相互对冲，不代表损失规模大。本案例不是所有渠道同向变化，不称辛普森反转。需人工检查相关产品动作、渠道配置与未知渠道归属记录，不能由此认定支付故障或直接提出切换渠道。

## 范例 R2：提交支付率上升，渠道效率改善但结构拖累

范围：Web × 注册新用户；按提交渠道分解，不与 R1 混用人群或贡献分母。

**Web 新用户提交支付率 +20.91%（7.70% -> 9.31%），+1.61pp，渠道内效率改善推动上涨，提交渠道结构变化反向拖累；不能把负结构贡献解释为整体支付恶化。**

1. **渠道结构在抵消部分上涨：** 结构效应为 -0.08pp，对净变化贡献 -5.27%。Payinsider 的提交人数占比 -17.45%（40.64% -> 33.55%），-7.09pp，结构效应为 -0.05pp；其两期平均提交支付率高于同一人群总体两期均值。
2. **渠道内效率改善覆盖了结构拖累：** 效率效应合计 +1.69pp，贡献 +105.02%。Stripe 自身提交支付率 +22.67%（7.18% -> 8.81%），+1.63pp，效率效应为 +1.02pp，是主要拉动渠道。

未归因项为 +0.00pp，贡献 +0.25%；不能因金额或人数较小就删除。效率与结构方向相反，但可比渠道与总体提交支付率均上升，不属于辛普森反转。需从产品动作明细核查对应配置或流程变化，尚不能把效率改善认定为某次产品优化的效果。

## 范例 R3：国家结构拖累，国家内效率改善推动整体上涨

范围：App 全体链路用户；按国家层级分解。与渠道分解是解释同一总体变化的不同视角，影响不能相加。

**App 提交支付率 +4.49%（42.23% -> 44.12%），+1.89pp，各国家层级内部提交支付率改善推动上涨；国家层级结构变化拖累 -0.21pp，未改变整体上涨方向。**

1. **提交人数结构变化抵消部分上涨：** 结构贡献 -10.91%。目标比率低于两期大盘平均值的 T2，提交人数占比 +3.66%（43.61% -> 45.21%），+1.60pp，结构影响 -0.20pp；T1 提交占比 -2.25%（51.50% -> 50.34%），-1.16pp，也构成拖累。
2. **国家层级内效率改善是主要拉动：** 效率效应 +2.10pp，贡献 +110.91%。T2 自身提交支付率 +9.31%（29.44% -> 32.18%），+2.74pp，效率影响 +1.22pp，是最大拉动层级。

T1、T2、T3 的组内提交支付率均上升，与总体同向，不属于辛普森反转。T3 的两期实际指标较低也不能直接证明付费意愿低。国家结构不能等同支付渠道配置变化；没有交叉证据时，不推断某渠道在某国家层级变差。效率改善对应的产品动作仍待检查。

## 范例 R4：DAU 下降与投放国家点击变化互为线索

范围：Web。国家映射由用户确认适用于本比较期；UK 合并为 GB，无效/未知国家单列，未分入 T2。点击、注册为周累计；DAU 为日均。

**Web 日均 DAU -2.38%（78,909 -> 77,028），日均减少 1,881，其中 T3 解释 60.90% 的减少；投放侧 T3 点击和注册也减少，方向一致，但尚不能确认投放造成了活跃用户减少。**

1. **T3 是 DAU 减少的主要国家层级：** 日均 DAU -6.99%（16,388 -> 15,243），日均减少 1,145。这是人数变化事实，不直接等于流量质量恶化。
2. **投放侧点击收缩集中在印度，存在其他国家对冲：** T3 周点击 -12.57%（214,225 -> 187,288），其中印度周点击 -14.36%（205,513 -> 176,008），减少量超过 T3 净减少量，说明其他 T3 国家合计对冲了部分减少。T3 投放归因注册人数 -12.71%（56,557 -> 49,371）。

上述是投放侧旁证；目前无法按同一批用户桥接点击、注册和活跃，也不能由国家层级 DAU 推导印度 DAU。需人工检查获客来源关联、新用户活跃和老用户回访，不能写“印度点击减少解释了多少 DAU”。结构影响已包含在后续总体比率中，不额外加到 LMDI 的 DAU 金额效应上。

## 范例 R5：先注册新老，再分别做主漏斗 LMDI

范围：Web 主动付费链路覆盖人群。链路覆盖金额与交易结果口径不强行视为相同；不把以下因素直接套到首订或积分包。

**Web 链路日均 GMV +12.03%（$67,278 -> $75,372），增加 $8,095，新老用户均增长；老用户贡献了更多金额增长，但两组核心过程因子不同。**

1. **老用户增长主要由曝光率提升推动：** 日均 GMV +9.64%（$55,227 -> $60,549），增加 $5,322；其曝光率 +5.82%（24.01% -> 25.41%），+1.40pp，LMDI 金额效应为 $3,271，提交支付率 +4.15%（51.84% -> 53.99%），+2.15pp为次要拉动，金额效应 $2,353。
2. **新用户增长主要由提交支付率提升推动：** 日均 GMV +23.01%（$12,050 -> $14,823），增加 $2,773；提交支付率 +20.91%（7.70% -> 9.31%），+1.61pp，金额效应 $2,542，曝光率 +9.70%（75.43% -> 82.74%），+7.31pp为次要拉动，金额效应 $1,239。

两组付费墙提交率均构成拖累；新用户的对应金额效应为 -$1,335，老用户为 -$465。这说明总收入上涨也应保留局部漏失。分组因子百分比各有分母，不能跨组相加；注册新老未知项须对账保留。没有产品动作证据，不把曝光改善解释为新增拦截策略，也不把提交率下降解释为涨价。
